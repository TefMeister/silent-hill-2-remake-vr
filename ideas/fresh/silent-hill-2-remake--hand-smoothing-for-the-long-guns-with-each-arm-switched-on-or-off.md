# Hand smoothing for the long guns, with each arm switched on or off

Order: 6009
From: the ideas repo, `games/silent-hill-2-remake.md` (<https://github.com/TefMeister/mod-ideas/blob/main/games/silent-hill-2-remake.md>), copied 2026-11-08

`[raw]` · `[looks doable]` — ⚠️ *not checked in Silent Hill 2; the route is the one Visceral RE8 already has*

**What Tefa said (2026-11-08):** *"hand smoothing for long weapons with the options to turn off hand smoothing only in
the left arm or right arm or both, i think some weapons could make use of it"*.

Reads as: smoothing that takes the shake out of the hands while a shotgun or rifle is held, with a switch for the left
arm, the right arm, or both, so each weapon can be tuned.

**What it'd take:** Visceral RE8 already has this shape: a One Euro filter on the controllers with a strength
slider and separate left and right switches, which runs only while a real gun is in hand (never melee, never bare
hands: the standing rule). For SH2 it would go into our C++ plugin, which already knows which weapon is held, plus a
menu entry with the three switches. The GitHub page Tefa remembers showing was not found in our notes on 2026-11-08.
